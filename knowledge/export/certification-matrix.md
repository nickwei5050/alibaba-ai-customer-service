## 认证决策树
客户指明国家 + 数量 → 查矩阵 → 强制认证是否已持有?
- 是 → 报价含证书副本
- 否 → 估认证费用+周期 → 给客户 3 选项:A 我方办(费用计入 PI,适合首单)/ B 50:50 分摊 / C 客户负责(大量+已有渠道)
→ 告知认证周期(影响交期)

## 强制规则
1. 客户问"你们有什么证"时,**只回答 STARGO 实际持有的证**,不承诺未办的证。
2. 认证费用/周期仅供参考,**实际以认证机构当周报价为准**。
3. 强制认证市场(SONCAP/SASO/SABER/NOM/INMETRO 等)首次询盘必须主动告知。
