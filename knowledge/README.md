# STARGO Knowledge Base (local)

Point `knowledge.obsidian_path` in `config.yaml` at this folder (or your real
Obsidian vault). Files are indexed by the retriever; the first folder level is
the category.

Recommended categories:

```
company/      who we are
products/     model specs
prices/       confirmed prices (the ONLY source of quotable prices)
battery/      battery options
shipping/     shipping rules (not final freight quotes)
sample/       sample policy
distributor/  distributor policy
faq/          certificates, common questions
rules/        hard rules / forbidden promises
scripts/      reusable reply templates
```

The files here are **samples** so the system runs out of the box — replace them
with your real STARGO content.
