# STARGO Upgrade Kit

Portable SEO / GEO / data-consistency assets for the STARGO Motor website
(www.stargomoto.com). Authored without access to the live `stargo` Next.js repo,
so it ships as **drop-in data + helpers** you copy into that repo and wire into
your existing premium (GSAP / 3D / animated) pages.

It adds the content + metadata layer from the upgrade brief. It does **not**
remove or weaken any animation.

- **Start here:** [`INTEGRATION.md`](./INTEGRATION.md)
- **Fix inconsistent claims:** [`NORMALIZATION.md`](./NORMALIZATION.md)

See `INTEGRATION.md` for the file-by-file map and step-by-step wiring.
